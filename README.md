# UNIV NA04 · 오늘의 강의

한국어 대학 수업 일일 평가 사이트. 빌드 없이 GitHub Pages에서 실행합니다.

## 기능

- 학교·교수·학과별 수업 등록 및 검색
- 날짜별 만족도, 이해도, 전달력, 수업 구성 1~5점 평가
- 동일 수업·날짜의 평가 수정 (중복 저장 방지)
- 평가 기록 검색 및 JSON 내려받기
- 모바일 화면, 키보드 조작, 입력값 검증

## 저장 범위

현재는 **개인 기록용 초기 버전**입니다. localStorage에 저장하므로 다른 사람/기기와 공유되지 않으며 학생 인증은 없습니다. 브라우저 데이터 삭제 시 기록이 삭제됩니다. 실제 다중 사용자 운영에는 인증, 서버 데이터베이스, 접근 제어, 중복 평가 방지, 신고 및 관리자 기능을 추가해야 합니다. 샘플 교수명이나 가상 평가는 포함하지 않습니다.

## 배포

Settings → Pages → Source를 GitHub Actions로 지정하세요. main에 push하면 `.github/workflows/pages.yml`이 정적 파일만 배포합니다.

기본 주소: https://noarmy04.github.io/univ.NA04.github.io/

`univ.NA04.github.io`는 저장소 이름이므로 이 이름 자체가 GitHub Pages 도메인이 되지 않습니다.

정적 HTTP 서버로 이 디렉터리를 제공하세요. 설치하거나 빌드할 패키지가 없습니다.
