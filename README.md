# UNIV NA04

한양대학교 ERICA 캠퍼스 학생을 위한 시간표·수업 일일 평가·익명 커뮤니티입니다.

- [사이트 이용하기](https://noarmy04.github.io/univ.NA04.github.io/)
- [GitHub 저장소](https://github.com/Noarmy04/univ.NA04.github.io)

## 주요 기능

### 오늘의 강의

- 선택한 시간표에 등록된 과목만 평가할 수 있습니다.
- 오늘 수업이 있는 과목을 시작 시간순으로 먼저 표시합니다.
- 실제 수업 날짜와 세션을 지정하고 전체 만족도·이해도·전달력·수업 구성을 1~5점으로 평가합니다.
- 한줄평을 작성하고 기존 평가를 수정할 수 있습니다.
- 저장한 평가는 익명으로 자동 공개되며, 연결에 실패하면 개인 저장 후 공개 게시 대기 상태로 표시합니다.
- 등록 과목 수·오늘 남긴 평가 수·평균 만족도는 화면 하단에서 확인합니다.

### 내 시간표

- 연도와 1학기·여름학기·2학기·겨울학기를 구분하고, 같은 학기에도 여러 버전을 만들 수 있습니다.
- 과목·교수·수업번호·강의실을 검색해 과목과 수업 시간을 추가합니다.
- 요일·시간·교수·강의실을 주간 시간표에서 확인하고 수정합니다. 시간은 5분 단위로 입력하며 충돌을 확인합니다.
- 제공된 `ERICA_2026_2_과목데이터.xlsx`의 강좌 2,156건을 사용합니다. 다른 학기의 최신 개설 정보는 포함하지 않으며, 시간 미지정 강좌는 직접 입력해야 합니다.
- 과목 상세에서 수업 방식과 시험 정보를 확인하고 관리합니다. 학생 작성 정보는 공식 안내와 함께 확인해주세요.

#### 에브리타임 시간표 가져오기

내 시간표 → 에타 링크로 가져오기에서 공개 `https://everytime.kr/@...` 링크를 입력합니다.

1. 과목·교수·분반·시간·강의실 미리보기를 확인합니다.
2. 새 시간표로 저장하거나 같은 학기의 현재 시간표에 추가합니다.
3. 중복 과목은 건너뛰며, 시간 충돌이 있으면 전체 저장을 중단합니다.

수업번호·과목·교수를 ERICA 강좌 자료와 대조합니다. 매칭되지 않는 강좌나 다른 학기의 강좌는 원본 정보를 사용하며 임의로 다른 분반을 지정하지 않습니다. 에타의 시간과 강의실을 우선합니다.

공개 링크만 지원하며 비공개·만료 링크는 가져올 수 없습니다. 에타 로그인 정보는 받지 않고 공유자 이름과 친구 정보를 수집하지 않습니다. 가져오기는 익명 로그인 후 Supabase Edge Function을 통해 처리하며, 입력 링크와 원본 응답을 데이터베이스에 저장하지 않습니다. 외부 서비스의 형식 변경에 따라 연동 수정이 필요할 수 있습니다.

### 평가 기록

**학생들의 평가**와 **내 평가**를 구분합니다.

- 다른 학생의 평가는 본인의 수업 평가를 1개 이상 서버에 공개 등록한 뒤 볼 수 있습니다. 개인 저장·게시 대기 상태는 열람 조건에 포함되지 않습니다.
- 학생들의 평가는 **과목 선택 → 주차 선택 → 평가 확인** 순서로 열람합니다.
- 같은 학기·학교·과목·교수·주간 수업 시간대의 평가는 하나의 과목 탭에 모이며, 다른 시간대의 분반은 분리됩니다.
- 같은 분반이 주중 여러 번 수업하는 경우, 같은 주차의 평가를 함께 표시합니다.
- 각 평가를 작은 목록으로 표시하고 전체 평점·한줄평과 작은 글씨의 이해도·전달력·수업 구성 점수를 제공합니다.
- 과목·교수·내용 검색, 평가 날짜·주차 필터, 날짜순·평점순 정렬을 지원합니다.
- 내 평가에서는 개인 기록 수정과 JSON 내려받기를 지원합니다.

#### 주차 계산

주차 기준일(개강일)부터 **7일 단위**로 계산하며 휴일도 포함합니다. 기준일 이전 날짜는 `개강 전`, 기준일이 없는 기록은 `주차 기준일 미설정`으로 표시합니다.

- 2026년 1학기 기본 기준일: 2026-03-03
- 2026년 2학기 기본 기준일: 2026-09-01
- 예: 2026년 2학기의 2026-11-10 수업은 11주차
- 기준일 수정: 내 시간표 → 버전 정보 수정 → 주차 기준일
- 다른 연도·계절학기의 기준일은 직접 설정합니다.

기본 기준일 출처: [한양대학교 2026학년도 학사일정 안내](https://econ.hanyang.ac.kr/sub/sub05_01.php?boardid=notice&idx=940&mNum=5&mode=view&sNum=1). 주차 표시는 날짜 계산 결과이며 개별 과목의 휴강·보강에 따른 진도 주차와 다를 수 있습니다. 새 평가는 저장 당시의 주차 기준일을 함께 보관합니다.

### 토론 & 커뮤니티

- 같은 수업을 듣는 학생들이 익명으로 대화하는 공간입니다. 일일 평점과 한줄평은 평가 기록에서 확인합니다.
- 해당 수업의 평가를 서버에 등록해야 대화를 읽고 참여할 수 있습니다. 참여 조건은 서버에서 확인합니다.
- 같은 학기·학교·과목·교수·주간 수업 시간대라면 날짜·주차·세션이 달라도 같은 방에 모입니다. 다른 시간대의 분반은 분리합니다.
- 연속된 수업 시간 구간은 합쳐 비교하고, 시간이 없는 강좌는 수업번호로 구분합니다.
- 오늘의 시간표 과목을 먼저, 내 시간표의 나머지 과목을 그 아래에 표시합니다. 시간표 밖 과목은 검색으로 찾습니다.
- 첫 참여 시 비속어·문제 소지가 있는 표현 사용에 따른 이용 제한 안내를 표시합니다.
- 기본 금칙 표현 차단, 반복 사용 제한, 메시지 신고를 지원합니다. 열린 대화는 10초 간격으로 새 글을 확인합니다.
- 메시지는 고정 토론방 ID에 연결됩니다. 평가나 분반 정보를 수정해도 기존 메시지는 원래 방에 남습니다.
- 서버에서 평가 데이터의 자료형·날짜·점수·분반 구조를 검증하고, 잘못된 기존 기록은 공유 조회에서 제외합니다.

## 데이터 저장과 개인정보

| 구분 | 저장 위치·범위 |
| --- | --- |
| 시간표·등록 과목·개인 평가 사본 | 이용 중인 브라우저에 저장, 다른 기기와 자동 동기화하지 않음 |

브라우저 데이터를 삭제하면 개인 시간표·평가 사본과 기존 익명 작성자 접근을 잃을 수 있습니다. 브라우저의 사본 삭제만으로 서버에 공개한 글이 자동 삭제되지는 않습니다. 필요한 개인 기록은 미리 내려받아 보관해주세요.

재학생 인증은 제공하지 않습니다. 개인정보, 비공개 시험 문항, 타인을 식별하거나 비방하는 내용은 작성하지 마세요.

### 평가 초기화 이력

운영자 요청으로 **2026-11-10 20:29:44 KST (11:29:44 UTC)** 이전의 기존 평가를 초기화했습니다. 당시 서버 공유 평가 3건을 삭제하고 남은 평가 0건을 확인했습니다.

`review-reset.js`는 해당 기준 시각까지 작성된 개인 평가와 게시 대기 기록을 브라우저에서 제거합니다. 최신 사이트를 다시 열 때 적용되며, 과목·시간표·익명 로그인과 기준 시각 이후 새 평가는 유지합니다.

## 저장소 공개 범위와 수정 권한

현재 이 저장소는 **공개(public)** 상태입니다.

- 누구나 사이트에 접속하고 저장소 코드를 열람·다운로드·포크할 수 있습니다.
- 원본 저장소의 직접 수정과 push는 쓰기 권한을 부여받은 계정만 가능합니다. 외부인의 복사본 수정은 원본에 자동 반영되지 않습니다.
- 조직 구성원에게도 역할에 따라 권한이 부여됩니다. 조직 소속이라는 이유만으로 모두 관리자 권한을 갖는 것은 아닙니다.
- GitHub Free 조직에서는 공개 저장소로 GitHub Pages를 운영합니다. 현재 구성을 유지한 채 저장소를 비공개로 바꾸면 Pages 운영이 중단됩니다.
- 비공개 저장소에서 공개 사이트를 운영하려면 GitHub Team 등 지원 요금제 또는 다른 호스팅 구성이 필요합니다. 저장소 비공개 전환은 보류한 상태입니다.

저장소가 비공개여도 방문자의 브라우저에 전달되는 HTML·CSS·JavaScript는 확인할 수 있습니다. 관리자 키·비밀번호 같은 비밀 정보는 공개 파일에 넣으면 안 됩니다.

참고: [GitHub Pages 지원 범위](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages).

## 개발·배포

HTML·CSS·JavaScript로 구성된 정적 사이트이며, 익명 평가·대화는 Supabase를 사용합니다.

| 파일·폴더 | 역할 |
| --- | --- |
| `index.html`, `style.css`, `community.css` | 화면 구조와 스타일 |
| `app.js`, `community.js`, `review-hub.js` | 수업 평가·조회·화면 구성 |
| `term-model.js`, `timetable.js` | 학기·시간표 관리 |
| `academic-week.js`, `review-group-model.js` | 주차 계산과 과목별 평가 묶음 |
| `discussion-model.js`, `anonymous.js` | 분반 구분과 익명 서버 연동 |
| `everytime-model.js`, `everytime-import.js` | 에타 링크 가져오기 |
| `review-reset.js` | 기존 평가 초기화 |
| `page-help.js` | 화면별 이용 안내 |
| `backend/` | 서버 구성·권한·검증 자료 |
| `.github/workflows/pages.yml` | GitHub Pages 자동 배포 |

서버 구성과 제한 사항은 [backend/README.md](backend/README.md)를 참고하세요. `anonymous-config.js`에는 공개용 프로젝트 URL과 publishable key만 사용합니다. 관리자 키와 비밀번호는 프런트엔드에 포함하지 않습니다.

### 검증

Node.js가 설치된 환경에서 저장소 폴더 내에서 실행합니다.

```sh
node test-timetable.cjs
node test-everytime.cjs
node test-discussion.cjs
node test-academic-week.cjs
node test-review-groups.cjs
node test-review-reset.cjs
node test-p1-security.cjs
```

화면 변경은 브라우저에서도 확인합니다. 서버의 권한·참여 조건 변경은 `backend/`의 관련 롤백 검증 SQL로 확인합니다.

### 배포 절차

1. 변경 사항을 구현하고 필요한 검증을 수행합니다.
2. 필요한 데이터베이스 변경을 먼저 Supabase에 적용·검증합니다.
3. 변경 사항을 커밋하고 `main`에 push합니다.
4. GitHub Actions의 `Deploy GitHub Pages` 성공과 공개 사이트를 확인합니다.

수동 복구용 `workflow_dispatch`도 지원합니다. 배포에는 워크플로에서 지정한 정적 파일만 포함하며 `backend/`와 테스트 파일은 Pages에 배포하지 않습니다.
