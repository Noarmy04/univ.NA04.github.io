# UNIV NA04 오늘의 강의

사이트: https://noarmy04.github.io/univ.NA04.github.io/

## 기능

- 학교·교수·학과별 과목 등록과 수업 방식·시험 정보 관리
- 요일·시간·강의실별 주간 시간표 등록과 수정
- 수업 날짜·세션별 만족도, 이해도, 전달력, 수업 구성 평가
- 평가 저장 시 익명으로 자동 공개, 기존 개인 기록은 자동 이전하지 않음
- 평가별 익명 대화, 첫 참여 안내 확인, 10초 간격 새 글 확인
- 교수님·과목·수업 날짜 검색과 날짜순·평점순 정렬
- 개인 기록 JSON 내려받기

## 저장 범위

개인 시간표와 과목, 평가 사본은 브라우저에 보관합니다.
새로 작성하거나 수정해 저장한 평가는 Supabase에 익명으로 공개됩니다.
익명 세션은 브라우저에 보관되며 데이터를 지우면 이전 작성자로 접근할 수 없습니다.
학생 인증은 없으며 시험 정보는 이용자가 작성한 내용입니다.

## 운영과 검증

익명 평가·대화의 서버 구조, 제한과 검증은 backend/README.md를 참고하세요.
공개용 프로젝트 URL과 publishable key만 anonymous-config.js에 포함합니다.
관리자 키나 비밀번호를 프런트엔드에 넣지 않습니다.

기본 작업 완료 범위는 커밋과 푸시까지입니다. 푸시해도 공개 사이트는 자동으로 갱신되지 않습니다.
GitHub Pages는 사용자가 별도로 승인한 수동 GitHub Actions 실행으로 정적 공개 파일만 배포합니다.
데이터베이스 스키마 변경도 별도로 승인받아 Supabase에 적용합니다.
