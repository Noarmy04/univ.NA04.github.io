# UNIV NA04 · 오늘의 강의

사이트: https://noarmy04.github.io/univ.NA04.github.io/

## 기능

- 학교·교수·학과별 과목 등록과 수정
- 과목별 수업 진행 방식과 시험 정보
- 과목 상세 안에 실제 수업 날짜별 세션 표시
- 같은 날 강의·실습 등 서로 다른 세션 평가
- 실제 수업 날짜와 평가 작성·수정 시각 분리
- 평가 검색 및 JSON 내려받기
- GitHub Issues 기반 학생 공유와 과목 가져오기

## 공유와 개인 저장

개인 기록은 기존 univ-na04-v1 localStorage에 보관하며 자동 공개하지 않습니다.
과목 상세 또는 평가 기록의 공유 버튼으로 내용을 확인한 뒤 GitHub 로그인과 게시를 완료해야 공유됩니다.
계정명과 내용이 공개됩니다. 다른 학생은 학생 공유에서 새로고침하면 같은 내용을 볼 수 있습니다.
원문에서 작성자가 수정할 수 있으며 이슈를 닫으면 공유 목록에서 제외됩니다.

공유 데이터는 univ-na04:v2 마커와 JSON 코드 블록이며 share-model.js에서 검증합니다.
열린 이슈를 최신 수정 순으로 100개씩 읽고 더 보기로 이전 기록을 불러옵니다.
동일 작성자·과목·날짜·세션의 중복 게시물은 불러온 기록 중 가장 최근 것만 표시합니다.
공개 API 제한이나 연결 오류는 재시도 안내로 표시합니다.
새로고침은 전체 목록을 초기화합니다.

GitHub 계정은 재학생 인증이 아닙니다. 시험 정보는 학생 작성 내용이므로 공식 안내를 확인하세요.
사이트 안에서 로그인·즉시 게시하려면 별도 인증 서버와 데이터베이스가 필요합니다.
토큰이나 비밀번호를 사이트 파일에 넣지 않습니다.
