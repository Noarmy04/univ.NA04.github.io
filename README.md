# UNIV NA04 오늘의 강의

사이트: https://noarmy04.github.io/univ.NA04.github.io/

## 기능

- 학교·교수·학과별 과목 등록과 수업 방식·시험 정보 관리
- 요일·시간·강의실별 주간 시간표 등록과 수정
- 수업 날짜·세션별 만족도, 이해도, 전달력, 수업 구성 평가
- 평가 저장 시 익명으로 자동 공개, 기존 개인 기록은 자동 이전하지 않음
- 평가별 익명 대화, 첫 참여 안내 확인, 10초 간격 새 글 확인
- 교수님·과목·수업 날짜 검색과 날짜순·평점순 정렬
- 개인 기록 JSON 내려받기

## 저장 범위

오늘의 강의에서는 평가할 수업을 먼저 표시하고 요약 통계는 화면 맨 아래에 표시합니다.
다른 학생의 평가 열람에는 본인의 평가 1개 이상 공개 등록이 필요하며, 서버에서도 이 조건을 확인합니다. 게시 대기·개인 저장 상태만으로는 열람할 수 없습니다.

개인 시간표와 과목, 평가 사본은 브라우저에 보관합니다.
새로 작성하거나 수정해 저장한 평가는 Supabase에 익명으로 공개됩니다.
익명 세션은 브라우저에 보관되며 데이터를 지우면 이전 작성자로 접근할 수 없습니다.
학생 인증은 없으며 시험 정보는 이용자가 작성한 내용입니다.

## 운영과 검증

시간표는 연도, 1학기·여름학기·2학기·겨울학기, 버전 이름으로 나누어 이 브라우저에 저장합니다.
주간 시간표는 내부 스크롤 없이 전체 시간대를 표시하며, 수업 칸에서 상세 정보를 열 수 있습니다.
이용 안내는 별도 메뉴 대신 오늘의 강의·내 시간표·평가 기록·토론의 각 화면 하단에 표시합니다.
선택한 시간표에 담긴 과목만 평가 목록에 표시하며, 평가 진입과 저장 때도 이를 확인합니다.
오늘의 강의는 오늘 요일에 수업이 있는 과목을 시작 시간순으로 먼저 표시합니다. 다른 학생 평가의 날짜 필터는 공유 영역에 별도로 두며, 내 수업 정렬이나 평가 작성창의 기본 날짜에 영향을 주지 않습니다. 날짜 필터의 기본값은 전체 날짜입니다.
기존 과목·평가 기록은 보관하며 이전 시간표 일정은 기본 버전으로 이전합니다. 일정이 없던 기존 과목은 과목 추가의 ‘이전에 등록한 과목에서 선택’에서 다시 담을 수 있습니다.

catalog.js는 제공된 ERICA_2026_2_과목데이터.xlsx의 강좌 목록 2,156건을 변환한 자료입니다.
수업번호로 분반을 구별하고 과목·교수·강의실·시간을 불러옵니다. 같은 요일·강의실의 연속 시간은 합칩니다.
시간이 지정되지 않은 강좌는 과목을 담은 뒤 직접 시간을 입력합니다. 다른 학기의 최신 개설 정보는 포함하지 않으며, 원본 자료 학기를 선택 화면에 표시합니다.
토론의 기존 과목 평가 참여 조건과 첫 참여 경고 문구는 유지합니다.

검증: node test-timetable.cjs. 브라우저에서 강좌 검색·시간 자동 반영·중복 시간 차단·학기별 목록 분리·평가 저장과 새로고침 후 보존을 확인했습니다.

2026-11-10 08:52:38 UTC까지 작성된 평가는 운영자 요청으로 초기화했습니다. 연결된 공개 토론과 신고도 함께 정리합니다.
review-reset.js는 사이트를 다시 여는 브라우저에서도 해당 시점까지의 개인 평가·게시 대기 기록을 제거합니다. 과목·시간표·익명 로그인은 유지하며 이후 새 평가는 보존합니다.

익명 평가·대화의 서버 구조, 제한과 검증은 backend/README.md를 참고하세요.
공개용 프로젝트 URL과 publishable key만 anonymous-config.js에 포함합니다.
관리자 키나 비밀번호를 프런트엔드에 넣지 않습니다.

기본 작업 완료 범위는 검증, 커밋, 푸시, 배포와 공개 사이트 확인까지입니다.
main 브랜치에 푸시하면 GitHub Actions가 정적 공개 파일을 GitHub Pages에 자동 배포합니다.
필요한 데이터베이스 변경은 먼저 Supabase에 적용·검증한 후 관련 화면을 배포합니다.
유료 요금제 변경이나 과금 서비스 활성화에는 별도 승인이 필요합니다.

## 에타 시간표 가져오기

내 시간표 → 에타 링크로 가져오기에서 공개 https://everytime.kr/@... 링크를 입력합니다. 미리보기에서 강좌와 분반을 확인한 뒤 새 시간표로 저장하거나 같은 학기의 현재 시간표에 추가합니다. 기존 시간표와 평가는 보존하며, 중복 과목은 건너뛰고 시간 충돌이 있으면 전체 저장을 중단합니다.
공개 공유 API의 수업번호·과목·교수를 ERICA 2026년 2학기 목록과 대조합니다. 다른 학기 또는 매칭되지 않는 강좌는 에타의 원본 정보로 추가하며 자동으로 다른 분반을 지정하지 않습니다. 에타의 시간과 강의실을 우선하고 5분 단위 시간을 유지합니다.
Supabase Edge Function everytime-import는 사용자 JWT를 요구하며, 고정된 에타 공개 조회 주소만 호출합니다. 에타 로그인 쿠키나 비밀번호는 받지 않으며 친구 정보·공유자 이름을 수집하지 않습니다. URL·응답을 데이터베이스에 저장하지 않습니다. 비공개·만료 링크는 오류를 표시합니다. 함수별 실행은 기존 Free 한도에 포함되며 유료 요금제를 활성화하지 않습니다. 외부 서비스의 공개 형식 변경 시 연동 수정이 필요할 수 있습니다.
검증: node test-everytime.cjs, node test-timetable.cjs, node test-review-reset.cjs.
