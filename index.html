수업을 등록하고 과목 상세에서 수업 방식과 시험 정보를 기록하세요. 같은 과목 안에서도 실제 수업 날짜와 세션(예: 3주차 강의 / 오후 실습)을 나누어 평가할 수 있습니다.

수업 날짜와 작성 날짜

수업 날짜는 실제 수업이 열린 날입니다. 작성·수정 시간은 별도로 기록되며, 같은 날짜에도 다른 세션을 추가할 수 있습니다.

학생 간 공유

개인 기록은 이 브라우저에 저장됩니다. 공개 공유는 GitHub 로그인을 통해 게시를 완료하면 다른 학생의 화면에도 표시됩니다. 공유할 때 GitHub 계정명과 내용이 공개됩니다. 사이트에서 공유 버튼만 누르는 것으로 게시가 완료되지는 않습니다.

공유 기록 수정·신고

공유 기록의 원문 링크에서 작성자가 수정하거나 닫을 수 있습니다. 닫힌 게시글은 공유 목록에서 제외됩니다. 신고·정정은 원문에서 관리자에게 알려주세요. GitHub 계정은 재학생 인증이 아니며, 공개 기록은 학생 작성 정보입니다.

기록 보관

개인 기록은 다른 기기와 자동 동기화되지 않습니다. 브라우저 데이터 삭제 전에 평가 기록의 내려받기를 이용하세요. 공개된 정보는 오늘의 강의 아래 공유 기록에서 다시 불러올 수 있습니다.

서로 존중하는 피드백

수업 경험과 개선점에 집중해주세요. 시험 정보는 확인된 일정·범위·유형을 적고, 개인정보나 비공개 시험 문항은 공유하지 마세요. 실제 대학이나 교수님의 공식 안내는 별도로 확인해주세요.
