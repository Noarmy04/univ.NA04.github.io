# 익명 평가 및 대화 활성화

이 기능은 Supabase 연결 전에는 활성화되지 않습니다. 기존 GitHub 공유 기능을 유지합니다.

1. Supabase 프로젝트에 `anonymous.sql`을 1회 마이그레이션합니다.
2. Authentication 설정에서 Anonymous Sign-Ins를 활성화합니다.
3. `anonymous-config.js`에 프로젝트 URL과 publishable key를 설정합니다. service-role key는 넣지 않습니다.
4. 익명 사용자 2명으로 평가 저장·공개 조회·대화·수정 권한·참여 안내·신고·제한 처리를 검증한 후 배포합니다.

새로 저장하는 평가는 자동 공개합니다. 기존 개인 기록은 자동 이전하지 않습니다.
익명 대화는 평가별로 별명이 달라지며 이메일·사용자 UUID를 조회 응답에 포함하지 않습니다.
익명 세션은 브라우저에 보관됩니다. 브라우저 데이터를 지우면 이전 익명 사용자로의 접근을 잃습니다.
제한은 해당 익명 사용자 기준으로 적용되며 실제 사람의 재가입까지 막는 학생 인증은 아닙니다.

서버는 글 길이, 수업 날짜와 점수를 검사하고 글쓰기 간격을 5초로 제한합니다.
기본 금칙 표현은 서버에서 거부하며 3회 위반하면 24시간 글쓰기를 제한합니다.
단순 단어 목록은 모든 유해 표현을 판별하지 못하므로 신고 내용은 관리자가 검토해야 합니다.
신고는 private reports 테이블에만 저장되고 관리자만 조회할 수 있습니다.

공개 평가는 최신 100개, 대화는 해당 평가의 최근 100개를 표시합니다.
실시간 전송이 아니라 대화 새로고침으로 새 메시지를 불러옵니다.
연결 실패한 평가는 개인 저장 후 게시 대기로 표시하고 재시도를 제공합니다.

공개 활성화 전 이용 안내의 기존 GitHub 공유 설명을 익명 자동 공개 설명으로 변경해야 합니다.
현재 단계에서는 아직 실제 Supabase 데이터베이스에 마이그레이션하거나 공개 배포하지 않았습니다.
